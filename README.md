# FEEL AGAIN

Responsive static homepage for Feel Again, built from the approved editorial design system and homepage copy.

## Structure

- `index.html` — homepage content and semantic structure
- `styles.css` — responsive layout and visual system
- `assets/references/` — approved visual references
- `docs/` — source handoff, content, and implementation specifications

Open `index.html` directly for a local preview or deploy the repository as a static site.
