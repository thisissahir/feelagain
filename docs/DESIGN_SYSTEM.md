# FEEL AGAIN — DESIGN SYSTEM

## Palette
- Warm Bone `#F2E7D8`
- Raspberry `#B2255A`
- Deep Brown `#3E2B24`
- Plum `#700845`
- Lilac `#CBA5CE`
- Ochre `#B58034`
- Acid Olive `#CBC459`
- Peach `#F0AC97`
- Burnt Orange `#C24D08`
- Powder Blue `#B3C1DE`

## Page-level distribution
- 45–50% Warm Bone
- 20–25% Raspberry + Plum
- 10–12% Peach
- 6–8% Powder Blue
- 5–7% Olive
- remaining 5–8% Ochre / Orange / Lilac

Never use all colors equally in one section.

## Typography
Use two families only.

Display serif:
- Cormorant Garamond / EB Garamond / Libre Baskerville

Sans:
- Inter / Manrope / IBM Plex Sans

Desktop:
- H1 72–92px
- H2 48–62px
- H3 30–38px
- body 17–20px
- labels 12–14px uppercase

Mobile:
- H1 46–56px
- H2 36–44px
- body 17–18px

## Grid
Desktop:
- max width 1280px
- outer margins 64–80px
- 12 columns
- 24px gaps

Mobile:
- 20–24px margins

## Spacing
8 / 16 / 24 / 32 / 48 / 64 / 96 / 128

## Buttons
Primary:
- Raspberry background
- light text
- 12–16px radius
- 14px 24px padding

Secondary:
- transparent
- 1px Plum border
- Plum text

No circles. No pill extremes.

## Media framing
Only:
- portrait 4:5
- landscape 3:2

No circular masks, arches, torn edges, or faux-polaroids.
