# IMPLEMENTATION RULES

## Responsive
Mobile:
- hero stacks text then artwork
- recognition becomes single-column
- split sections stack
- offer details become rows
- Start Here cards stack
- 20–24px side margins

## Accessibility
- minimum 16px body, target 17–18px
- WCAG AA contrast
- visible focus states
- semantic landmarks
- 44px minimum tap targets
- prefers-reduced-motion support

## Motion
Allowed:
- 250–450ms fade / translate
- subtle image reveal

Not allowed:
- floating shapes
- cursor effects
- bouncing CTAs
- constant parallax
- animated blobs

## Real-web test
Every section must feel like part of the same website:
- same max width
- same grid
- same labels
- same button system
- same spacing scale
- same typography hierarchy
